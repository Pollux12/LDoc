cityrp.net

An item is interactable an object held in an inventory.

This system tries to be as compatable as possible with the two existing methods of registering items. This class acts as a bridge between the two different item systems and the inventory system.

You should not create items using anything in this object, please see itemCore for how to register an item. You also shouldn't directly call anything in here to create a new item object. This object is only used for interacting with items in an inventory, not creating them. All registered items are automatically created into an item object.
