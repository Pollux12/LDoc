 View source »

Called when a new item is created for the first time. This is only called for when an item is first created, not when it is loaded from the database. This is used for calling item.onCreate, which is intended for creating initial persistent item data such as inventories.

Parameters

  • item ITEM

    Item being create.

  • inventory INVENTORY

    Inventory the item is being created in.
